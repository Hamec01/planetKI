# 🌍 Planetki

> **2D Grand Strategy / Civilization Simulation & RTS in Godot 4**
> From First Fire Tribe to Space Age.

---

## 🏛️ Project Overview

**Planetki** is an emergent civilization simulation and RTS built with Godot 4.7+. It models living demography, dynamic traditions & laws, faith emergence, institutional building systems, map exploration, military skirmishes, and systemic civilization dilemmas.

### ✨ Key Systems
- **Emergent Civilization Engine**: 12 exclusive tradition branches, dynamic government type calculations (`CultureMemory`), and systemic narrative event trees.
- **RTS Interface & Controls**: Top economy bar, permanent bottom command dock (`BottomDockBar`), cursor-anchored contextual action popups, and mouse/keyboard navigation.
- **Deep Building Systems**: Interactive building institutions with job assignments, upgrades, production pipelines, and historical chronicles.
- **Demography & Cohort Simulation**: Real population cohorts (Children, Youth, Adults, Elders), housing dynamics, loyalty, and order.
- **Military & Generals**: Formations, marches, battlefield resolution, and general traits.
- **Living Pantheon**: Dynamic emergence of faith, commandments, and cults based on player choices.
